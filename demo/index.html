C2PA Content Credentials

Check an image’s content credentials.

Reads the C2PA data embedded in an image file: who signed it, which tool made it, whether it declares AI generation, when, and whether the file still matches what was signed. It cannot tell whether an image without credentials is AI-generated, and it does not check signers against a trust list.

Sign your own images: proofcan.com. More on how this works: proofcan.com/pulse/check.
